# Skills Guide

## Cuando Usar Skills
- Usar skills globales si el usuario las menciona o el trabajo coincide claramente con su descripcion.
- Usar skills locales solo para contexto propio del repo.
- No instalar ni ejecutar skills externos para operaciones con secretos.

## Skills Recomendadas
- `openai-docs`: solo para dudas de Codex/OpenAI o uso de skills/agentes.
- `skill-creator`: al crear o modificar `.codex/skills/**/SKILL.md`.

## Reglas
- Leer `SKILL.md` completo antes de aplicar sus instrucciones.
- No delegar la interpretacion de una skill a un subagente.
- Si una skill apunta a referencias, leer solo las necesarias para la tarea.
